# Overview
This repository contains the implementation code for the "Deep-learning quasi-particle masses from QCD equation of state" research paper. The main program QuasiEos_HotQCD_lnZ.ipynb is developed using TensorFlow and designed to run in Jupyter Notebook environments. The code produces visualization images and numerical results that are automatically saved in dedicated directories. Pre-trained models are also provided for direct use.

# Key Features
Jupyter Notebook compatible interface
TensorFlow implementation
Automatic result organization
Pre-trained model availability
